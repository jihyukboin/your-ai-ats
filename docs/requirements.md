# 요구사항 정의서 · 포트폴리오 준비 플래너

개발 직무 지원자가 취업 준비 시간 중 일부를 오픈소스 이슈 읽기와 메모에 배정한다. 기존 기업 분석·이력서 화면에서 ‘포트폴리오 준비 플래너’로 들어간다. GitHub의 공개 입문 이슈와 Stack Overflow 참고 질문을 사용한다. 저장 단위는 이슈 링크, 읽을 날짜, 시작·종료 시각, 메모가 담긴 한 건의 계획이다.

## 도메인과 시나리오

| 사용자 요청 예 | 판단에 필요한 정보 | 도구 없이 생기는 오답 |
|---|---|---|
| 내일 14시부터 15시까지 Python 이슈 읽기 계획을 짜줘 | 열린 이슈의 언어, 본문 길이, 읽기·메모 시간 | 이미 닫힌 이슈나 주어진 시간에 읽기 어려운 이슈를 제안할 수 있다. |
| 같은 조건에서 종료만 14시 10분으로 바꿔줘 | 직전 조건, 첫 후보들의 예상 시간, 다음 페이지 후보 | 날짜·언어까지 바꾸거나 긴 이슈를 다시 제안할 수 있다. |
| 오늘 14:00부터 14:02까지 Python 이슈를 정리하고 싶어 | 가용 시간, 후보별 최소 필요 시간, 재계획 상한 | 메모 시간조차 확보할 수 없는 계획을 저장 대상으로 제안할 수 있다. |
| Python 이슈를 읽고 싶어 | 누락된 날짜·시간 | 사용자가 정하지 않은 일정을 임의로 확정할 수 있다. |

기준 조건은 읽을 날짜와 시작 시각, 선호 조건은 언어, 제약 조건은 종료 시각이다. 읽기 분량은 GitHub 이슈 본문 글자 수로 추정한다. 건강·금융 상담은 제공하지 않는다. 후보 검색, 식별자 기반 상세 조회, 다른 출처의 참고 질문 검색을 각각 독립된 외부 API 툴로 사용한다. 실제 호출 결과와 제공기관별 조건은 [Tool 정의서](tools.md)와 [실측 데이터](evidence/live-tools.json)에 있다.

## 필수 기능

| 번호 | 취업 준비 도메인에서의 수락 기준 |
|---|---|
| F3001 | Agent가 사용하는 3개 도구의 이름·사용 시점·입출력 스키마를 조회할 수 있고 실패가 공통 형식으로 반환된다. |
| F3002 | 언어에 맞는 열린 입문 이슈의 식별자·이름을 조회한다. 기본 조회일과 요청일·관측일 차이를 표시한다. |
| F3003 | 식별자로 상세 조회한 본문 길이를 사용한다. 분량을 확인할 수 없는 후보는 판단에서 제외한다. |
| F3004 | 다른 제공기관에서 언어별 참고 질문과 원문을 찾고 빈 결과를 구분한다. |
| F3005 | 언어·날짜·시작·종료 시각을 추출하고 조건이 부족하면 되묻는다. |
| F3006 | 요청과 보유 정보에 따라 필요한 도구와 순서를 결정한다. 도움말에는 도구를 호출하지 않는다. |
| F3007 | 검색 결과의 식별자를 상세 조회에 넘긴다. 개별 실패를 기록하고 나머지 근거로 판단한다. |
| F3008 | 예상 읽기·메모 시간과 가용 시간을 비교하고 가장 늦게 시작할 수 있는 시각을 계산한다. |
| F3009 | 적합 후보가 없으면 다음 페이지를 탐색한다. 중복 조회를 피하고 상한에 이르면 종료 사유를 알린다. |
| F3010 | 같은 세션의 후속 요청은 변경한 조건만 갱신한다. |
| F3011 | 후보·판단 기준·참고 자료·근거와 제외 사유를 함께 제공한다. |
| F3012 | 단계 진입·종료, 도구 요청·응답·소요 시간, 실행 흐름을 결정한 판단과 이유를 발행한다. |
| F3013 | 독립 구독자가 원본 이벤트를 세션·실행별로 저장한다. 구독 실패에도 메인 응답이 가능하다. |
| F3014 | 세션별 로그 목록·상세·삭제를 제공한다. 수정 메서드는 허용하지 않는다. |
| F3015 | 추천 계획의 대상·일자·시각·생성 일시를 저장·조회하고 겹치는 일정도 저장한 뒤 알린다. |
| F3016 | 계획을 수정·삭제하고 목록에 반영한다. |
| F3017 | FastAPI가 대화·계획·로그를 별도 경로로 제공한다. |
| F3018 | Vue 대화·계획 관리 화면에서 실제 서버의 응답을 사용한다. |
| F3019 | 실행 순서, 도구 이력, 재계획 지점, 요청 처리 중 상태와 오류를 표시한다. |

## 비기능 요구사항

| 번호 | 수락 기준 |
|---|---|
| NF3001~NF3002 | 선택적 인증 정보는 서버 환경변수로 읽고 소스·응답·화면에 값을 싣지 않는다. 제공기관 실패는 사용자 안내로 변환한다. |
| NF3003 | 상세·참고자료 일부가 실패해도 남은 정보로 응답한다. |
| NF3004 | 대안 탐색 횟수를 제한하고 종료 사유를 기록한다. |
| NF3005 | 대표 요청의 전체 처리 시간을 측정하고 외부 호출 시간과 재생 시간을 구분한다. |
| NF3006 | Vue와 FastAPI를 분리하고 그래프, 도구, 이벤트 구독, 저장소의 책임을 파일로 나눈다. |
| NF3007 | 제공기관의 이용 조건·호출 한도·출처를 기록하고 참고 질문의 출처와 저작자를 보존한다. |

## 심화 기능 범위

이번 제출 범위는 기본 기능이다. F3020 로깅 Agent 이상 진단, F3021 Planner·Worker 분리, F3022 Vector DB 검색, F3023 외부 캘린더 연동은 선택하지 않았다. 기존 기업 분석·이력서 적합도 평가·자기소개서 기능은 같은 앱에서 별도로 이용할 수 있다.
